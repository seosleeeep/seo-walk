# V2 속도 승급 기준 오프라인 비교 (2026-11-17)

학습된 model_29999.pt의 기존 진단 로그를 재분석했다. 정책, 보상, 학습 승급 기준은 변경하지 않았다.

## 결과

| 직진 명령 | 기존 기준 통과 | 평균 회전속도 기준 | 평균 + RMS 0.35 | 평균 + RMS 0.50 |
|---|---:|---:|---:|---:|
| 0.8 m/s | 0/10 | 9/10 | 9/10 | 9/10 |
| 1.0 m/s | 0/10 | 9/10 | 9/10 | 9/10 |

0 및 0.5 m/s는 현재 cap=1.0의 승급 평가 대상(vx >= 0.8 × cap)이 아니다.

기존 기준은 매 순간 몸체 z축 각속도의 절댓값이 0.2 rad/s 이하여야 하며, 속도·방향·옆 이동 조건까지 동시에 만족한 표본이 80% 이상이어야 한다. 보행 중 좌우로 번갈아 회전하는 움직임도 순간 각속도 기준에서는 실패로 처리된다.

수정 후보는 속도·방향·옆 이동 조건의 동시 만족 비율 80%를 유지하면서, 회전 조건을 구간 평균 각속도의 절댓값 0.2 rad/s 이하로 바꾼 것이다. 평균만 쓰면 큰 좌우 진동이 상쇄될 수 있어 RMS(제곱 평균의 제곱근) 상한 0.35 및 0.50 rad/s를 추가한 후보도 비교했다. 두 RMS 후보의 결과는 같으므로 이 자료만으로 적정 상한을 결정할 수 없다. 이 수치는 검증된 학습 설정이 아니라 비교용 후보이다.

## 여전히 실패하는 구간

두 속도 모두 4~8초 구간에서 옆 이동 제한을 충분히 만족하지 못했다. 처음 1초를 제외한 평가 표본 중, 구간 시작 방향 기준 옆 이동 15cm 이내 비율은 0.8 m/s에서 73.51%, 1.0 m/s에서 74.17%였다. 요구 비율 80%에 미달한다. 해당 구간의 RMS 각속도는 각각 0.241, 0.283 rad/s이다.

따라서 순간 각속도 조건 완화만으로 직진 문제가 해결된다고 볼 수 없다. 전체 10초 진단에서 최대 옆 이동은 각각 약 41.1cm, 47.2cm였다. 짧은 구간마다 기준 방향을 새로 잡는 승급 평가와, 출발점 기준 장거리 직진 성능을 구분해야 한다.

## 해석 범위

- 각 명령별 seed 42의 10초 재생 하나를 2초 구간 5개, 3초 구간 3개, 4초 구간 2개로 나눴다. 구간 길이가 다른 묶음끼리는 같은 데이터를 재사용하므로 독립적인 10회 실험이 아니다.
- 구간 시작 위치·방향을 기준으로 재계산하고 첫 1초를 제외했다. 실제 학습의 명령 변경, 외란, 랜덤화, reset 상황을 재현한 것은 아니다. 따라서 9/10은 학습 성공률 90% 또는 승급 가능성을 입증하지 않는다.
- 실제 승급의 최소 200개 구간, 두 연속 평가 창, 단계별 최소 1000 iteration 조건도 이번 자료로 검증하지 않았다.
- body z축 각속도는 몸체가 기울어지면 world heading 변화율과 동일하지 않다. 현재 후보는 기존 코드와 비교하기 위해 body 각속도를 그대로 사용한다.
- 이 결과는 기존 순간 각속도 조건이 평가 재생에서 병목이라는 근거다. 학습 로그의 성공률 0 원인을 모두 규명한 것은 아니다.

## 다음 단계

실제 학습 조건에서 기존 판정과 후보 판정을 동시에 기록하되 승급에는 기존 기준을 유지하는 비교 계측이 우선이다. 속도·옆속도·각속도·방향·옆 이동별 탈락 비율, reset 실패, 명령 변경을 함께 기록한다. 여러 seed에서 판정을 확인한 뒤 새 실험 버전에서 승급 기준을 변경하고, 출발점 기준 장거리 직진 평가를 별도로 유지한다. 이번 분석만으로 추가 3만 회 학습을 시작하지 않는다.

## 재현

V2 프로젝트에서 원본 진단 ZIP을 푼 diagnostics 폴더를 지정한다.

```bash
python scripts/audit_speed_gate.py --diagnostics-dir /path/to/diagnostics --output gate_audit.json
python scripts/test_gate_audit.py
```

Python 표준 라이브러리만 사용한다. 6개 단위 검사를 통과했다. 실제 GPU 학습 검사는 수행하지 않았다. 상세 수치 및 state.csv SHA-256은 analysis.json에 포함되어 있다.
