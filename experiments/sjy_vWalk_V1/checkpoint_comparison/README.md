# V1 체크포인트 비교: 10000 / 20000 / 29999

**결론: 학습량 증가에 따른 개선은 일부 있으나, 모든 속도에서 일관되게 좋아지지 않는다. 1m/s에서는 29999가 속도, 20000이 방향 유지에 유리하다. 2m/s 이상 속도 추종은 세 모델 모두 부족하다.**

분석일: 2026-11-17. 한 학습 실행의 서로 다른 checkpoint를 seed42, 전진 명령별10초로 비교했다. 각500개, 총6000개 표본이다.
평가 CSV에서 평균속도·RMSE·최대 횡이탈·최대 heading을 재계산하여 JSON과 일치함을 확인했다.
속도 평균/RMSE는 time_s>=2.0(401표본) 구간이며 시작 방향 기준 root-link 전진속도다.

평균 수평 속력은 각 표본 sqrt(v_forward²+v_lateral²)의 평균이다. 방향과 무관한 이동량 진단용이며, 올바른 방향의 속도 추종 지표를 대체하지 않는다.

## 결과 해석

- 1m/s: 10000→20000에서 평균 전진속도0.438→0.915, 최대 heading71.8→11.3도로 개선. 29999에서는 속도가1.003으로 더 맞지만 heading21.4도, 횡이탈74.1cm로 20000보다 악화.
- 1.5m/s: 20000과29999 평균속도는0.752/0.763으로 비슷하고 목표1.5에 미달. 29999에서 횡이탈은129.8→90.8cm로 감소했지만 방향 오차는약22도로 남는다.
- 2m/s: 20000→29999에서 평균 전진속도0.459→0.225로 감소. 횡이탈144.0→25.8cm 감소만으로 개선을 선언할 수 없다. 이동량도 크게 줄었다.
- 2.5m/s: 평균 전진속도는20000의0.360에서29999의0.308로 감소. 방향 오차는36.6→5.5도로 감소하지만 명령 속도 추종은 여전히 실패.
- 모든 평가가 duration_completed이나, 이것은10초 동안 환경 종료가 없었다는 뜻이다. 장기 안정성·낙상률·팔 자세 정상 여부는 입증하지 않는다.

## 다음 실험 판단

1. 현재29999는1m/s 속도 기준,20000은1m/s 방향 유지 기준의 비교 모델로 모두 보존한다. 단일 최고 모델로 확정하지 않는다.
2. 동일 조건 seed/초기상태를 바꾼 반복 평가와 정지 평가를 추가한다. 한 seed 결과만으로 일반화하지 않는다.
3. 같은 설정으로 무작정 추가 학습하기보다 몸체 기준 vx/vy, yaw-rate, 관절 토크와 포화율, 접촉·팔 관절각을 기록한다.
4. 직진/속도 실패 원인을 관측·관절 매핑·보상·모터제한 중 하나로 단정할 근거는 아직 없다. 학습 TensorBoard 곡선도 제공되지 않았다.
5. 다음 학습 변경은 원인을 좁힌 뒤 한 항목씩 비교한다. 고속 명령은 설정상3m/s 범위 안이므로 범위 밖 명령만으로 설명하지 않는다.

## 출처 및 재현 한계

- 원본: v1_checkpoint_comparison.zip. ZIP SHA256은 PROVENANCE.json 참조.

- evaluations는 원본 CSV·JSON을 보존한다. 동일29999 평가의 중복 파일은 기존 폴더와 바이트 일치 확인 후 Git에서 기존 자료를 참조한다.
- TensorBoard 이벤트·모델 가중치·영상은 제공되지 않았다.
- params YAML의 Python 태그는 실행하지 않았다. unsafe_load로 로딩하지 않는다.
