## 평가 조건과 근거

- 모델: model_29999.pt; 실행: 2026-11-16_02-42-37_v1_velocity_straight.
- 각 명령 10초, seed42, 500개 표본, 간격0.02초. 4개 평가 모두 duration_completed.
- 제공 평가 코드 기준 waypoint 보정 없는 전진 명령. 실제 서버 평가 소스의 해시는 제공되지 않았다.
- 속도는 시작 방향에 투영한 root-link 속도. 평균과 RMSE는 time_s >= 2.0 구간(401표본).
- 2000개 CSV 표본의 유한값·시간 간격을 확인하고 평균/RMSE/최대 횡이탈/heading 요약값을 재계산해 일치 확인.
- 한 seed에서 속도별1회 평가다. 안정성 일반화, 팔 대칭, 낙상률을 입증하는 자료는 아니다.

## 해석

- 1m/s: 초기 가속 이후 평균 약1m/s를 유지하지만 횡이탈74.1cm, 최대 heading21.4도로 직진 문제가 남는다.
- 1.5m/s: 2~6초에도 약0.95m/s에 그치고 마지막2초 평균0.420m/s로 감소한다. 단순 초기 가속 지연만으로 설명되지 않는다.
- 2m/s: 초기 이후 약0.22m/s에 머문다. 2.5m/s: 약0.31m/s에 머문다.
- 고속 명령에서 작은 횡이탈/heading은 짧은 이동 거리와 함께 해석해야 한다. 직진 개선으로 단정하지 않는다.
- 1/1.5/2m/s의 마지막 heading과 횡이탈은 음수다. 로봇 화면의 좌/우 방향은 뷰 방향과 좌표 convention 확인 없이 단정하지 않는다.
- 10초 완료는 이 구간에 환경 종료가 없었다는 뜻이다. 낙상·팔 자세·에너지·장시간 안정성을 별도로 확인해야 한다.
- 회전만으로 전진 속도 저하 전체를 설명할 수 없다. 특히2.5m/s는 heading 오차가 작아도 매우 느리다.

## 실제 학습 params에서 확인한 설정

- num_envs1024, timestep0.002초, decimation10, episode30초.
- seed42, max_iterations30000, rollout24, epoch5, minibatch4, 초기 learning_rate2.5e-6/adaptive, resume=false.
- vx[-1.5,3.0], vy[-1.5,1.5], yaw-rate[-1.6,1.6], 명령 유지2~4초, forward_proportion0.5, still_proportion0.1.
- play=false, distance=null, 기본 보행 위상1.5Hz.
- 대칭 증강 및 mirror loss 활성, 계수0.005. base_height 가중치-20, arm_posture -0.1.
- 따라서2/2.5m/s 명령은 설정상 범위 안이다. 범위 밖 명령(OOD)만으로 실패를 설명할 수 없다. 실제 속도별 학습 경험량은 이 파일만으로 알 수 없다.
- env.yaml은 일부 보상 함수를 term_name으로만 기록한다. reward_config.json 전체 파라미터와 실제 소스까지 완전히 복원하는 스냅샷은 아니다.
